# ep001-titanic-key: sound-effect prompts

Optional. Make any of these by hand in ElevenLabs (Sound Effects) and upload it as `audio/sfx/<name>.mp3` (or .wav).
Until a file is uploaded, tools/sfx.mjs uses its synthetic recipe. Beds (loop = true) are crossfaded so they loop seamlessly.
